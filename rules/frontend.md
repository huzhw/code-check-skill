# JSP / 前端组检查规则（通用层）

> 适用：`.jsp`、`.ts`、`.tsx`、`.vue`、`.js`、`.jsx`、`.html` 文件，**任何项目通用**。
> （`js/v3/` 等构建产物目录已被过滤，此处均为手写源码）
> 加载时机：scan 分组输出中「JSP」「前端 TS/JS」组。
> 🔴 通用规则（`rules/general.md` 的破坏性操作 / 敏感信息 / 路径安全）与本文件**叠加生效**。
> 团队/项目专属规范（页面结构约定、权限码等）不在本文件——按项目档案或仓库自定义规范加载。

## 安全

| 检查点 | 典型隐患 |
|--------|---------|
| XSS | `dangerouslySetInnerHTML`、`v-html`、JSP 输出未转义、`innerHTML` 拼接用户输入 |
| 危险标签 | JSP `<%=` 直接输出请求参数、`<c:out escapeXml="false">` |
| URL 注入 | 前端拼 URL 带未编码用户输入 |
| 敏感信息 | 前端代码硬编码密钥/内网地址/token |
| 后端接口信任 | 前端校验当安全边界（后端必须再校验） |

## 框架正确性

| 检查点 | 典型隐患 |
|--------|---------|
| React key | 列表渲染无 key、用 index 当 key 且列表会重排 |
| 内存泄漏 | useEffect 未清理定时器/订阅/监听、组件卸载后 setState |
| 状态错误 | 闭包陈旧值、异步竞态（快速切换请求覆盖） |
| 空值渲染 | 接口数据未判空直接 `.map`/`.length`、可选链缺失 |
| 事件泄漏 | 全局事件/window 监听未在销毁时移除 |

## 构建与工程（通用）

| 检查点 | 隐患 |
|--------|------|
| 构建配置 | vite/webpack 入口新增了源码但产物目录规则会滤产物——检查以源码为准 |
| 依赖 | 新引依赖未锁版本、引入明显过维护状态的包 |
