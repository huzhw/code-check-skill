# 通用检查规则

> 适用：**所有组叠加生效**——破坏性操作 / 敏感信息 / 路径安全三节查任何语言都要带上。
> 本文件同时是「配置 XML」「配置文件」「其他」组的专属规则。

## 🔴 破坏性操作（任何组命中都必须列影响范围和可恢复性）

| 检查点 | 典型隐患 |
|--------|---------|
| 删文件/目录 | `rm -rf`、`os.remove`、`File.delete`、`FileUtils.deleteDirectory` |
| SQL 清表/无条件删改 | `DROP TABLE`、`TRUNCATE`、`DELETE FROM` 无 WHERE、`UPDATE` 无 WHERE |
| 删对象 | `DROP USER`/`DROP INDEX`/`DROP DATABASE`/`ALTER TABLE DROP COLUMN` |
| 权限变更 | `REVOKE`、收权限的授权语句 |
| 覆盖写无备份 | 整文件覆盖、rename 覆盖已存在文件 |

处理规则：必须列出**数据影响范围**和**能否恢复**；拿不准标「待确认」，不许直接放行。

## 🔴 敏感信息

| 检查点 | 典型隐患 |
|--------|---------|
| 硬编码密钥 | API key、数据库口令、 JWT secret 写死在代码/配置 |
| 日志泄密 | log 打印密码/token/身份证号/手机号明文 |
| 凭证入库 | `.env`、证书、私钥文件被 git add |

## 🔴 路径安全

| 检查点 | 典型隐患 |
|--------|---------|
| 解压未隔离 | 解压/写入直接落临时目录根，未在临时目录内加**随机子目录**隔离 |
| 路径穿越 | `../` 逃逸出目标子目录、Zip Slip |
| 文件名拼接 | 上传文件名直接 `new File(dir + name)`，未清洗 |
| 符号链接 | 软链指向外部目录 |

## 配置 XML / 配置文件（本文件专属部分）

| 检查点 | 隐患 |
|--------|------|
| 数据源/连接串 | 切环境配置未还原、密码明文变动 |
| Spring 配置 | Bean 循环依赖、事务代理失效（同类内调用 @Transactional 方法） |
| 路径/端口 | 配置的路径在目标环境不存在、端口冲突 |
| 环境隔离 | dev/test/prod 配置项串用、开关默认值指向危险行为 |

## 其他文件（无法归类时兜底）

按文件内容常识判断：脚本（.sh/.bat/.ps1）查破坏性命令和路径；markdown/文档查敏感信息；无法判断的改动列出来让用户自己过目，不瞎报。
